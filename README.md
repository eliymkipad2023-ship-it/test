# 経営者タスク管理アプリ

忙しい経営者向けの高機能タスク管理Webアプリケーション

## 🔐 セキュリティ

このアプリケーションはパスワード保護されており、認証されたユーザーのみがアクセスできます。

**初期パスワード**: `executive2026`

### パスワードの変更方法

1. `generate-hash.html` をブラウザで開く
2. 新しいパスワードを入力してハッシュを生成
3. 生成されたハッシュを `js/task-manager.js` の `passwordHash` に設定

## ✨ 主な機能

- 📝 タスクの追加・編集・削除
- ⭐ 優先度設定（高・中・低）
- 📁 カテゴリー分類（会議、プロジェクト、重要決定など）
- 📅 期限管理と期限超過の自動検出
- 📊 統計ダッシュボード
- 🔍 高度なフィルタリングと検索機能
- 💾 LocalStorageによるデータ永続化
- 📱 レスポンシブデザイン（モバイル対応）

## 🚀 使い方

1. ブラウザで `task-manager.html` を開く
2. パスワードを入力してログイン
3. 「+ 新しいタスクを追加」ボタンでタスク作成
4. フィルターや検索で効率的に管理

## 📂 ファイル構成

```
├── task-manager.html      # メインアプリケーション
├── css/
│   └── task-manager.css   # スタイルシート
├── js/
│   └── task-manager.js    # アプリケーションロジック
└── generate-hash.html     # パスワードハッシュ生成ツール
```

## 🔒 プライバシー

すべてのデータはブラウザのLocalStorageに保存され、サーバーには送信されません。
